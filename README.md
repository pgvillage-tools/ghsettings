# ghsettings

Manage the settings of GitHub repositories from a declarative config: repository settings and
a branch ruleset (pull request reviews, required checks, merge queue), for many repositories
across organizations.

It is used by [pgvillage/github-settings](https://github.com/pgvillage/github-settings) to keep
the repositories of the PgVillage organizations consistent.
